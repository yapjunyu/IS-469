## Agent skills

### Issue tracker

Before diagnosing a bug, starting a ticket or closing one, read `docs/agents/issue-tracker.md`. Specs and tickets live as GitHub issues.

### Triage labels

The five default labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), applied as GitHub labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Coding standards

Review rules (LLM calls, trace format, turn state, tests) live in `CODING_STANDARDS.md`. Read it when reviewing a diff.
